**Goal:** Implement versioned mapping gate duties and immutable durations, a narrowly proved local-failure path, and accepted global run retirement with exact finite replay protection.

**Architecture:** Keep normalization and gate/deadline authority in the shared controller; keep native termination evidence in the existing managed adapters. Workflows, native control actions, and task envelopes have independent compatibility versions.

## Global Constraints

- Preserve exactly `researcher`, `planner`, `implementer`, `validator`, their current modes, fresh task/child identities, independent validation, serial writer isolation, scope checks and conservative uncertainty handling.
- Workflow versions: exactly `1.0.0` and `2.0.0`. Task packet/result envelopes remain v1. Global profile becomes `2.0.0`, supporting control request `version: 1` and `version: 2`; workflow version is independent.
- V2 duration: default `300000`, safe integer `1..3600000`; trusted `maxTaskTimeoutMs` default `3600000`. V1 construction `timeoutMs` remains compatibility-only. No renewal or clamping.
- Global resident limits remain 128 runs and 4096 calls. Replay metadata, including reservations, is limited to 65536 logical identity records and 16777216 canonical UTF-8 bytes; no eviction or indefinite-lifetime promise.
- Unbounded workflow budgets do not remove deadlines, resource ceilings, cancellation, identity freshness, or independent acceptance.
- Native ownership and complete-input evidence reuse remain deferred. Keep collision checks and blanket writer invalidation.
- No provider calls, real runtime activation, global install, publication, credential/config changes, or weakening of stopped-run recovery. Fixtures use fake native contexts/executables and private owner-only `/var/tmp` roots; never rely on Bubblewrap-visible `/tmp`.
- Serial increment ownership includes source, tests, generated outputs, examples, affected inventories and documentation. Builders are not alone; preserve unrelated work. Parent owns Git integration and authorized commits/push; leaf builders do not mutate Git history.
- Existing approval-reviewed WSL recovery applies if the sandbox fails before shell startup; it is not blanket escalation approval.

## Review Focus

1. Asymmetric v1 association has different historical profile semantics; diagnosis must not silently weaken either profile (Task 1).
2. A ceiling below the default, unsafe clock addition, and returned-object mutation must reject or leave authority intact before consuming an attempt (Task 2).
3. Native wrapper/JSON decoding failure does not establish termination; delayed command/update/abort activity must retain stop and capacity (Task 3).
4. A callback racing retirement or teardown must still replace every native success surface; ordinary unrelated calls stay unaffected (Task 4).
5. Long identifiers, large acceptance summaries, and unresolved launch reservations can exhaust replay bytes before identity slots; neither bound may be bypassed by retirement (Task 4).
